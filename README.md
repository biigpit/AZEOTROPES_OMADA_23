# AZEOTROPES_TEAM_23

Διαγράμματα T–x για την παρατήρηση **αζεοτρόπου ελαχίστου σημείου ζέσεως**
σε μίγμα ισοπροπυλικής αλκοόλης (C₃H₇OH) – νερού, με βάση πειραματικές μετρήσεις.

## Εκτέλεση

```bash
uv run python azeotropa_omada_23.py
```

## Διαχείριση περιβάλλοντος

- **Συγχρονισμός πακέτων** (π.χ. σε άλλη συσκευή, από το `uv.lock`):
  ```bash
  uv sync
  ```
- **Προσθήκη νέας βιβλιοθήκης:**
  ```bash
  uv add <όνομα-πακέτου>
  ```
- **Αφαίρεση βιβλιοθήκης:**
  ```bash
  uv remove <όνομα-πακέτου>
  ```

Το `.venv/` φτιάχνεται αυτόματα από το uv και δεν ανεβαίνει στο git.
