# AZEOTROPES_TEAM_23

Διαγράμματα T–x για την παρατήρηση αζεοτρόπου ελαχίστου σημείου ζέσεως
σε μίγμα ισοπροπυλικής αλκοόλης (C₃H₇OH) – νερού, με βάση πειραματικές μετρήσεις.

Το παραπανω project αφορά μία εργαστηριακή αναφορά στην άσκηση Φ4 του μαθήματος "Δομή και Καταστάσεις της Ύλης" στο 3ο εξάμηνο της Σχολής Χημικών Μηχανικών του ΕΜΠ

Είναι μία ομαδική παραγωγή και αφορά την δημιουργία του διαγράμματος με βάση τα πειραματικλα στοιχεία αξιοποιώντας τις αντίστοιχες βιβλιοήκες της γλώσσας πργραμματισμού python

Η εργασία εκπονείται από την ομάδα 23.
